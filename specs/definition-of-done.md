# Definition of Done

Una funcionalidad se considera terminada cuando:

- Cumple todos los Acceptance Criteria.
- Tiene unit tests.
- Tiene tests E2E.
- Cumple WCAG 2.2.
- Está documentada.
- Tiene trazabilidad.
- Tiene validación de negocio y reglas relevantes.
- Tiene revisión de accesibilidad y usabilidad.
- La implementación queda alineada con la arquitectura y la estrategia del producto.
