# Benchmark Page

## Objetivo
Presentar métricas y rankings de forma comprensible para apoyar la decisión del usuario.

## Componentes principales
- Resumen de métricas relevantes
- Ranking por criterio comparativo
- Contexto de metodología y fuente
- Diferenciación entre rendimiento y recomendación
- Alertas para datos incompletos

## UX y contenido
- Usar gráficos simples o indicadores claros
- Evitar sobrecarga de información
- Asegurar que los datos tengan contexto
- Mantener la lectura accesible

## Acceptance Criteria
- El usuario entiende qué se está comparando y cómo.
- Las métricas muestran fuente o metodología cuando aplica.
- Se informa claramente cuando un benchmark no está disponible.
- La vista conserva una estructura legible y consistente.
