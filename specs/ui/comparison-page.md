# Comparison Page

## Objetivo
Permitir comparar de forma clara dos o más herramientas IA en paralelo.

## Componentes principales
- Selector de herramientas
- Matriz de comparación
- Resumen de diferencias clave
- Indicadores de fortaleza y limitación
- Acciones para guardar o continuar

## UX y contenido
- Mantener criterios homogéneos
- Resaltar diferencias funcionales relevantes
- Dar contexto cuando un dato no está disponible
- Utilizar una lectura fluida y escaneable

## Acceptance Criteria
- La vista permite comparar al menos dos herramientas.
- La selección puede cambiarse fácilmente.
- La matriz muestra diferencias de forma legible.
- La comparación conserva el contexto de decision.
