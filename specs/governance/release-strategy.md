# Release Strategy

## Versioning

Semantic Versioning

MAJOR.MINOR.PATCH

Ejemplos:

- 1.0.0
- 1.1.0
- 1.1.1

## Release Types

### Major
Cambios incompatibles.

### Minor
Nueva funcionalidad compatible.

### Patch
Corrección de errores.

## Release Flow

feature
↓
develop
↓
release/x.y.z
↓
main
↓
tag
↓
deployment
