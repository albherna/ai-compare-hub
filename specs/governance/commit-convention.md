# Commit Convention

Formato:

<type>(scope): description

Tipos permitidos:

- feat
- fix
- docs
- style
- refactor
- test
- chore
- build
- ci
- perf
- revert

Ejemplos:

- feat(auth): add login form
- fix(tasks): resolve board refresh issue
- docs(specs): update authentication rules
- test(auth): add login unit tests
- refactor(shared): simplify state management
- chore(repo): update project structure
- ci(workflow): add lint pipeline
- perf(search): improve filter response time
- revert(auth): rollback previous login fix
